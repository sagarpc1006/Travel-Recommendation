Create PHASE 1 of the EcoTrail 2.0 product design.

Do NOT create the full application screens yet.

============================================================
PRODUCT
============================================================

Product:
EcoTrail 2.0

Tagline:
"Travel Greener. Explore Smarter."

EcoTrail is an AI-powered sustainable and accessible travel platform.

Core product pillars:

1. AI-powered travel planning
2. Sustainable travel
3. Accessible / inclusive travel
4. Carbon awareness
5. Personalized recommendations
6. Eco-Twin alternatives
7. Explainable recommendations
8. Real travel data

The final product will be implemented using:

Frontend:
- React 18
- Vite
- JavaScript
- React Router
- Axios
- React-Leaflet / Leaflet
- Vanilla CSS

Backend:
- Django
- Django REST Framework

Authentication:
- Firebase Authentication
- Firebase Admin SDK

Database:
- PostgreSQL

AI:
- Google Gemini
- Groq fallback
